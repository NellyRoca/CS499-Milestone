# Elevate – Android Weight Tracking Application

## Project Overview

Elevate is an Android weight-tracking application originally developed
for CS-360: Mobile Architecture and Programming. The application allows
users to create an account, log in, record weight entries, establish a
goal weight, and monitor their progress.

This project was enhanced for the CS-499 Computer Science Capstone to
demonstrate skills in software engineering and design, algorithms and
data structures, and database development.

## Technologies

- Java
- Android Studio
- SQLite
- RecyclerView
- Android SDK
- Git/GitHub

## Capstone Enhancements

### Software Engineering and Design
- Improved dashboard organization and usability
- Improved input validation and error handling
- Improved application structure and maintainability
- Improved navigation and user interaction

### Algorithms and Data Structures
- Converted weight values from formatted Strings to numeric values
- Improved organization of weight history
- Added progress-to-goal calculations
- Added validation for calculation edge cases
- Improved data processing through the WeightEntry data structure

### Databases
- Added a `user_profiles` table
- Added display name and preferred weight unit
- Added database versioning and migration support
- Added reusable profile database methods
- Improved database queries for retrieving user-specific information
- Expanded database-driven dashboard information

## Project Purpose

The purpose of this enhancement project was to evaluate an existing
application and apply concepts learned throughout the Computer Science
program to improve its design, data management, algorithms, and
functionality.
